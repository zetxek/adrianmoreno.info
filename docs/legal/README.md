# Legal & compliance records

Records for third-party processors that handle personal data on behalf of
adrianmoreno.info.

For GDPR purposes the site owner is the **controller**; each vendor below is a
**processor**. A Data Processing Agreement must be in place with each one before it
starts handling personal data, and a copy retained here.

## Processors

| Vendor | Purpose | Personal data handled | Record |
|---|---|---|---|
| Resend | Newsletter delivery, subscriber storage | Email address, confirmation timestamp, engagement events | [resend.md](resend.md) |
| Formspree | Contact form delivery | Name, email address, message body | Not yet recorded |
| Vercel | Hosting, analytics | IP address, request metadata | Not yet recorded |

Formspree and Vercel predate this directory and are listed for completeness — they
need the same treatment when someone has a spare hour.

## Executed agreements

Vendor DPAs that were click-accepted or signed are stored alongside each record as
PDFs, named `<vendor>-dpa-<YYYY-MM-DD>.pdf` where the date is the version's effective
date, not the download date.

These are point-in-time snapshots for the audit trail. The authoritative version is
always the one in the vendor's own dashboard, which may have been updated since.
Re-check annually.
